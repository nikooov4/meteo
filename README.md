# MeteoBridge

Единое локальное приложение: карта осадков, архивы ERA5 и генерация суточных
прогнозов GrathCast. Веб-сервер, чтение ERA5 и управление файлами работают на C#.
По первой генерации сервер запускает постоянный Python-процесс модели на NVIDIA GPU.

## Запуск

```powershell
.\start_app.ps1
```

Адрес из консоли обычно `http://127.0.0.1:8766/`. В Visual Studio 2026 откройте
`MeteoBridge.sln`, выберите `MeteoBridge.Era5` и нажмите F5.
Нужны .NET 10 SDK и PowerShell 7+. На этой машине все зависимости подготовлены.
Для внешней папки ERA5: `./start_app.ps1 -Data 'D:\ERA5'`.

## Работа на сайте

- **Карта** показывает архивы ERA5. При пересечении времени источники выбираются
  по сохранённому приоритету.
- **Архив** загружает исходные файлы из Amazon S3 / NCAR, Google ARCO-ERA5 и
  Copernicus CDS и хранит суточные прогнозы GrathCast. При первом скачивании
  суточного файла приложение ставит в очередь подготовку входа для ИИ.
  Для ранее скачанных файлов есть кнопка «Подготовить для ИИ».
- **Генерация** принимает скачанный глобальный файл ERA5 на 24 непрерывных часа.
  При выборе архива прогноз запускается автоматически. Готовый вход
  сохраняется на диске и используется при повторных запусках. Поля для модели
  скачиваются напрямую из публичного архива Google ARCO-ERA5. Также можно
  выбрать готовый входной NetCDF или продолжить сохранённый прогноз.
- **Сравнение** показывает выбранный файл ERA5 рядом с прогнозом GrathCast.
  Две карты используют общие время, масштаб и цветовую шкалу. Архивная карта
  суммирует почасовые LSP за тот же шестичасовой интервал, что и кадр модели.

Один запуск создаёт один NetCDF на следующие 24 часа от конца покрытия входа
с четырьмя шагами по 6 часов. Результат автоматически попадает в архив GrathCast.
При первом запуске модель загружается в видеопамять и остаётся там до закрытия
приложения.

[Входной формат и генерация](docs/graphcast.md) · [Архивы ERA5 и их API](docs/era5_dotnet.md)

## Структура

| Папка | Назначение |
| --- | --- |
| `dotnet/MeteoBridge.Era5` | Единый сервер, архивы, карта и управление моделью |
| `web` | Карта, архив, генерация и сравнение |
| `workers/graphcast` | Рабочий код модели, закреплённые зависимости и источники весов |
| `runtime` | Подготовленные библиотеки, Python, GPU-окружение, веса и сторонний код |
| `data/era5` | Исходные метеорологические файлы |
| `data/graphcast-inputs` | Подготовленные входы модели |
| `data/graphcast` | Готовые суточные прогнозы и кадры карты |
| `scripts` | Подготовка зависимостей и обновление решения Visual Studio |
| `dotnet/MeteoBridge.Era5.Tests` | Модульные и интеграционные проверки xUnit |
| `tests` | Проверки JavaScript для веб-страниц |
| `docs` | Документация приложения |
| `artifacts` | Журналы, результаты проверок и публикации |

Один запуск приложения управляет всем жизненным циклом. Отдельных экспериментальных
CLI, CPU-окружения и второй реализации карты в проекте нет. Бинарные зависимости,
пользовательские данные и секреты исключены из Git. Корневая `.venv` нужна только
для разработки и подготовки библиотек.

## Подготовка на новой Windows-машине

Нужны .NET 10 SDK, PowerShell 7+, uv и подходящий драйвер NVIDIA.

```powershell
uv sync --frozen
.\scripts\setup_runtime.ps1
.\scripts\setup_graphcast.ps1
.\start_app.ps1
```

Подготовка GrathCast устанавливает закреплённые пакеты, проверяет SHA256 весов
и исходников, создаёт входной пример из двух состояний. Повторная проверка
без сети и загрузки GPU: `./scripts/setup_graphcast.ps1 -VerifyOnly`.
Windows GPU использует сторонний WinJAX; WSL2 не требуется.
