# Библиотеки основного приложения

`netcdf/` содержит NetCDF-C и его x64 DLL-зависимости; `plotly/` — Plotly.js.
Это библиотеки C/JavaScript, а не Python-сервис. Приложение не читает `.venv`.

Подготовка на Windows из уже установленного окружения:

```powershell
uv sync --frozen --no-dev
.\scripts\setup_runtime.ps1
dotnet build MeteoBridge.sln -c Release
```

Скрипт копирует библиотеки, сведения о пакетах и доступные лицензии из `.venv`.
Для этого устанавливаются только NetCDF4/Plotly с их зависимостями, без старого
исследовательского приложения, Streamlit, SciPy, pandas и других научных пакетов.
`manifest.json` фиксирует версии, размеры и SHA256. Скопированные файлы локальные,
не добавляются в Git и попадают в сборку/публикацию C#.
После обновления библиотек повторите подготовку и сборку.
Не заменяйте DLL при работающем сервере; остановите его перед обновлением.

Другие сборки можно задать через `METEOBRIDGE_NETCDF_LIBRARY` и
`METEOBRIDGE_PLOTLY_JS`. На Linux используется системная `libnetcdf.so`.
Для распространения сторонних бинарников отдельно проверьте условия всех
включённых зависимостей; содержимое wheel не является аудитом лицензий.
