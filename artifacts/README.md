# Результаты проверок

`validation/` — результаты проверки текущего C#-сайта, сравнения с Python и
проверки реальной загрузки NCAR. Исторические измерения не переписываются:
пути внутри старых JSON/XML относятся к структуре на момент измерения.

`logs/` — локальные журналы сервера; `publish/` — локальная публикация .NET.
Эти две папки игнорируются Git. Они не являются источниками ERA5.
Отчёты прежних прогонов сохранены как история, а не описание текущего состава
проекта. Актуальная проверка сайта после удаления исследований — `site-only-full.xml`.
