# Структура проекта ERA5

## Рабочая часть

- `dotnet/MeteoBridge.Era5` — сервер, индекс, workers и загрузки NCAR.
- `web` — единственный источник HTML-шаблонов и геометрии карты.
- `data/era5` — реальные исходные файлы; имя и байты файлов сохранены.
- `runtime` — сторонние библиотеки, скопированные `scripts/setup_runtime.ps1`.
- `tests` — интеграционные проверки сервера и структуры проекта.
- `scripts` — подготовка библиотек и обновление решения Visual Studio.
- `artifacts/validation` — доказательства проверок текущего приложения.

C# находит корень по `MeteoBridge.sln`, а не по Python-манифесту.
Сборка копирует HTML, геометрию, Plotly.js, нативные DLL и лицензии.
При запуске не импортируется Python.

## Удалённая исследовательская часть

По запросу пользователя `research` удалена целиком: старый Python-код, Streamlit,
CLI, научные команды, эксперименты, материалы защиты, калибровочные данные и DWD.
Удалены параметр запуска `-Python`, старый бенчмарк и ссылки Visual Studio.
Реальные исходные NCAR-файлы в `data/era5` и библиотеки работающего сайта сохранены.

`pyproject.toml` больше не устанавливает Python-приложение или CLI.
NetCDF4 и Plotly нужны только для подготовки локальных библиотек; NumPy,
HTTPX, pytest и Ruff — для разработки и интеграционных проверок.
Сайт не зависит от этого окружения после подготовки `runtime`.
Для подготовки без инструментов разработки: `uv sync --frozen --no-dev`.

## Проверка после изменения структуры

Из корня:

```powershell
uv sync --frozen
.\scripts\setup_runtime.ps1
.\scripts\update_solution.ps1
dotnet build MeteoBridge.sln -c Release
uv run --frozen pytest -q -p no:cacheprovider --junitxml=artifacts/validation/site-only-full.xml
uv run --frozen ruff check tests
node --test tests/map_viewer.test.cjs
```

`tests/test_project_layout.py` проверяет существование и уникальность ссылок
Visual Studio, независимость C# от Python-окружения и отсутствие старого приложения.
`tests/test_era5_dotnet.py` проверяет реальные API, очереди, точность,
занятый порт, отмену/докачку и обновление карты.
`tests/map_viewer.test.cjs` запускается на Node.js 24 без сторонних пакетов:
проверяет продолжение после перемотки, гонки запросов, явную паузу и размеры карты.
`tests/test_multiformat.py` и `tests/raster_fixtures.py` проверяют реальные GRIB
и GeoTIFF через поставляемый GDAL: приоритеты, заполнение ячеек и часов,
накопления, разные сетки, внутренние маски и перепроекцию. Python GDAL не нужен.
Браузерные тесты также проверяют подпись источников и плавную смену файлов.
`tests/test_archive_sources.py` проверяет онлайн-каталоги через локальные NCAR/GCS
серверы, пагинацию ARCO, побайтное сохранение исходного Google NetCDF и докачку.
Проверяются все 24 кадра Google-файла, удаление и повторная загрузка.
`tests/archive_viewer.test.cjs` проверяет смену источника и ссылки на архив,
удаление файлов и защиту от запоздавшего ответа прежнего каталога.

Проверка кадров не импортирует удалённый ридер: известны все исходные значения
маленьких временных NetCDF, ожидаемый порядок координат, UTC-интервалы, пропуски,
маски и преобразование метров в миллиметры. Проверяются все 60 часов тестового
архива, включая 12 часов без данных и повторяющийся файл.

## Что можно очищать

Пересоздаются `.vs`, `bin`, `obj`, `.dotnet-home`, `.uv-cache`, `__pycache__`,
`.pytest_cache`, `.ruff_cache`, `.hypothesis` и локальные логи.
Нельзя считать кэшем `data/era5`, отчёты проверок или пользовательские HTML/PNG.
`.venv` нужна для разработки/тестов, но не для уже подготовленного сайта.
`runtime` нужен для повторной сборки; бинарные библиотеки также входят в её результат.

## История проверок

После удаления исследовательской части прошли все 9 актуальных тестов и Ruff.
Release-сборка .NET и Debug-сборка установленным MSBuild Visual Studio успешны.
Карта и вкладка загрузок работают; все 13 исходных ERA5 сохранены с теми же SHA256.
Результаты: `artifacts/validation/site-only-full.xml` и `artifacts/validation/site-only.json`.

Сохранённые XML/JSON в `artifacts/validation` относятся к состоянию проекта
на момент прогона. Прежние 176/180 тестов включали удалённую научную часть;
это не количество тестов текущего сайта. Новая проверка не запускает архивный код.
Замеры сравнения с прежним Python-ридером сохранены как история, но команда
их повторения удалена вместе с самим ридером.
