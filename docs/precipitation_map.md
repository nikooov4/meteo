# Карта и анимация осадков

Добавлено 2026-10-18. Карта показывает исходные почасовые amounts реального
NSF NCAR ERA5 LSP для выбранного региона и ОДНОГО initialization cycle.
LSP — крупномасштабная компонента осадков, не total precipitation и не станционные
измерения. Это визуализация архива, не прогноз текущей погоды и не сертификат Query.

## Посмотреть

В локальном Streamlit:

```powershell
uv run streamlit run ui/app.py --server.address 127.0.0.1
```

В боковом меню выбрать **Карта осадков**, оставить найденный локальный ERA5-файл,
при необходимости изменить регион и нажать **Построить карту**. Доступны Play/Pause,
ползунок часа, масштабирование, значения под курсором и скачивание HTML/metadata.
Для выбора другого цикла укажите его ISO-время с UTC offset; пустое поле выбирает
первый цикл файла. После установки зависимостей сеть не нужна.

Отдельный HTML без запущенного сервера:

```powershell
uv run python scripts/build_precipitation_map.py --input data/scale/ncar-lsp-small/e5.oper.fc.sfc.accumu.128_142_lsp.ll025sc.2023010106_2023011606.nc --output outputs/maps/era5_lsp_animation.html
# --bbox WEST EAST SOUTH NORTH; по умолчанию: -15 65 35 72
# --cycle 2023-01-01T06:00:00Z --frames 12
```

Открыть `outputs/maps/era5_lsp_animation.html` браузером и нажать «Воспроизвести».
Наблюдаемые интервалы примера: 2023-01-01 06:00–18:00 UTC, 12 кадров.
Час на ползунке — конец соответствующего часового интервала.
Рядом сохраняется JSON с регионом, интервалами, размером выбранной сетки и hashes
HTML/границ. Полный SHA256 исходного NetCDF при каждом просмотре не пересчитывается;
размер и mtime источника записываются, исходный provenance остаётся в manifest.

Исходные NetCDF не входят в Git. Для чистого клона нужен отдельно загруженный
маленький NCAR-файл, описанный в [data_sources.md](data_sources.md); генерация
синтетического 200-GB набора для просмотра карты не нужна. Короткий CSV с одной
ячейкой не содержит целого пространственного поля.

## Корректность представления и ограничения

- Адаптер поддерживает NCAR ERA5 LSP `ds633.0`, units=m, документированную
  previous-hour convention HRES. Метры переводятся в mm. Почасовые amounts не
  вычитаются друг из друга как forecast-start cumulative totals.
- Все кадры относятся к одному cycle и одной переменной. Отдельные ячейки
  отображаются отдельно; никаких точных равенств между разными SeriesKey не возникает.
- Цветовая шкала фиксирована для всех кадров. Переход между часами дискретный;
  временная интерполяция и произвольное деление суточных сумм не выполняются.
  Пропуски/отрицательные значения скрыты и посчитаны в metadata.
- Это карта native grid с прямоугольными lon/lat axes и приближённым соотношением
  масштабов по средней широте региона. Геодезическая точность проекции и
  пространственное восстановление осадков не заявляются.
- Выбирается hyperslab нужной области. Не более 12 кадров и по умолчанию
  1 000 000 значений; абсолютный разрешённый предел аргумента max_cells — 2 000 000.
  Большая область отклоняется до чтения массива значений. Native HDF chunk может
  охватывать глобальное поле одного цикла; cache ограничен 64 MiB. Архив целиком
  не загружается. Это не новый 200-GB benchmark.
- Карта — дополнительный интерфейс данных. Scientific bounds, H completeness,
  proof checker, старые Gate A/B и заявления о новизне не изменены.

Границы из [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/)
поставляются локально, данные public domain; геометрия служит ориентиром.
[Исходный GeoJSON](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_admin_0_countries.geojson)
сокращён до геометрий без таблицы свойств. В HTML включены и geometry, и Plotly JS;
тайлы, CDN и ключи картографических сервисов не требуются. Применяются обычные
[Plotly frames и controls](https://plotly.com/python/animations/), новая библиотека
не добавлена, uv.lock не менялся.

Проверки: tests/test_precipitation_map.py проверяет orientation/longitude wrap,
разделение циклов, сохранение уменьшающихся почасовых amounts, invalid cells,
лимит до чтения, output frames и Streamlit. Фактический HTML отрисован в локальном
headless Edge с переключением на шестой кадр; evidence:
[map-render.json](../reports/validation/map-render.json). Измеренный scientific
pilot не перезапускался и не выдаётся за проверку карты.
