# Карта и анимация осадков

## Анимация всех реальных ERA5-файлов (2026-10-22)

В Streamlit выберите **Карта осадков → Реальный ERA5**, папку архива и начало/конец
периода в UTC. Поддерживается также путь к одному `.nc`: доступны все его циклы.
Нажмите **Построить карту**. В самой карте диапазон можно менять кнопкой **Показать**,
а скорость — переключателем 1/4/10 кадров в секунду. Конечное время не включается.
Список **Периоды с данными** показывает реальное покрытие файлов.

Индекс строится из координат времени всех `.nc` в выбранной папке, включая вложенные
папки. Поля осадков загружаются по запросу. Каждый кадр относится к отдельному часу;
переходы между циклами и файлами проходят автоматически. Для совпадающих часов
используется первый файл в порядке путей, без суммирования дубликатов.

Временная шкала непрерывна между выбранными границами. Часы без данных не пропускаются:
слой осадков очищается, шкала цвета скрывается, на карте появляется
**«В данном промежутке данные не найдены»**. Последний доступный кадр не переносится
в разрыв, и нулевые осадки не подставляются вместо отсутствующих значений.
Можно выбрать период, целиком находящийся в разрыве.

В `era5-weather-reference` сейчас 12 файлов: 4320 часов с данными и 4056 часов
разрывов с 2023-01-01 06:00 до 2023-12-16 06:00 UTC.
Сервер кадров запускается автоматически на свободном порту `127.0.0.1` вместе с
построением карты. В браузере хранятся максимум четыре кадра, на сервере — два
пространственно прореженных цикла. По умолчанию один кадр содержит до 100 000
отображаемых ячеек. Исходные файлы не меняются. Все файлы должны иметь одинаковую сетку.
NetCDF-чтение сервера, Streamlit и общего API защищено общим lock.

Скачанный HTML реального архива требует работающего MeteoBridge: он обращается к
локальному серверу за кадрами. После перезапуска приложения карту нужно построить
заново. Прежний CLI-экспорт одного цикла, описанный ниже, остаётся автономным.

Исправление после переноса проекта (2026-10-22): Streamlit автоматически находит
реальные NCAR ERA5 в `data/real` и `data/scale`, а также завершённые наборы
синтетики v2. Путь считается от каталога проекта. NetCDF читается через короткий
Windows-путь, если библиотека не поддерживает кириллицу; файлы не копируются.
Исходный путь сохраняется в метаданных. Обход требует доступных коротких имён NTFS.

Быстрый запуск из PowerShell:

```powershell
.\start_app.ps1
# Открыть http://127.0.0.1:8501/?view=map и нажать «Построить карту».

# Полный синтетический архив с выбором дат и сценария:
.\start_app.ps1 -Archive
# Открыть http://127.0.0.1:8765/
```

Архивный сервер строит стартовую страницу из текущего manifest, не меняя старые
HTML-карты. По умолчанию он не использует исторический scale report: отчёт другого
manifest отклоняется. Без отчёта шкала имеет фиксированный верхний предел 50 мм/ч,
а `color_scale_from_full_scan=false`. Данные и их контрольные суммы проверяются
при чтении выбранного shard. Прежние отчёты научных экспериментов сохраняются.

Архивный режим 2026-10-19: **10.084 GB v2**, выбор дат UTC и сценария слева
сверху, загрузка одного часа через общий FastAPI, ограниченный кеш.
[Основная карта](http://127.0.0.1:8765/synthetic_global_animation.html?view=10gb),
[команды сервера, диапазоны и проверки](../reports/weather_10gb.md).
Этот режим требует локального `serve_precipitation_map.py`; ниже описан также
прежний автономный режим одного цикла. Streamlit продолжает строить один цикл
выбранного manifest; для всего 10-GB диапазона используйте архивную карту.

Компактный viewer 2026-10-19: карта на доступную ширину, одна кнопка Play/Pause,
ползунок, «Весь мир», PNG и fullscreen. Настройки/данные раскрываются по клику.
[Проверка интерфейса и точная связь данных с экспериментами](../reports/map_ui_compact.md).

2026-10-19: добавлены мировой вид, зум колёсиком, сдвиг мышью, сброс масштаба
и отдельный источник «Синтетика v2». [Новый генератор, карта и команды](weather_generator_v2.md).
CLI теперь по умолчанию выбирает весь мир и ограничивает объём отображения
пространственной выборкой; исходный файл не меняется. При существующем output
CLI просит другой путь, сохраняя предыдущую карту и пользовательские изменения.

Добавлено 2026-10-18. Автономный CLI-экспорт показывает исходные почасовые amounts реального
NSF NCAR ERA5 LSP для выбранного региона и одного initialization cycle.
LSP — крупномасштабная компонента осадков, не total precipitation и не станционные
измерения. Это визуализация архива, не прогноз текущей погоды и не сертификат Query.

## Посмотреть

В локальном Streamlit:

```powershell
uv run streamlit run ui/app.py --server.address 127.0.0.1
```

В боковом меню выбрать **Карта осадков**, оставить найденную папку ERA5,
выбрать даты, при необходимости изменить регион и нажать **Построить карту**. Доступны Play/Pause,
ползунок часа, масштабирование, значения под курсором и скачивание HTML/metadata.
Все циклы выбранного периода воспроизводятся последовательно. После установки зависимостей
интернет не нужен; для архива должен работать локальный сервер кадров.

Отдельный HTML без запущенного сервера:

```powershell
uv run python scripts/build_precipitation_map.py --input data/scale/ncar-lsp-small/e5.oper.fc.sfc.accumu.128_142_lsp.ll025sc.2023010106_2023011606.nc --output outputs/maps/era5_lsp_animation.html
# --bbox WEST EAST SOUTH NORTH; по умолчанию: -180 180 -90 90
# --cycle 2023-01-01T06:00:00Z --frames 12
```

Открыть `outputs/maps/era5_lsp_animation.html` браузером и нажать «Воспроизвести».
Наблюдаемые интервалы примера: 2023-01-01 06:00–18:00 UTC, 12 кадров.
Час на ползунке — конец соответствующего часового интервала.
Рядом сохраняется JSON с регионом, интервалами, размером выбранной сетки и hashes
HTML/границ. Полный SHA256 исходного NetCDF при каждом просмотре не пересчитывается;
размер и mtime источника записываются, исходный provenance остаётся в manifest.

Исходные NetCDF не входят в Git. Для чистого клона нужен отдельно загруженный
маленький NCAR-файл, описанный в [data_sources.md](data_sources.md); генерация
синтетического 200-GB набора для просмотра карты не нужна. Короткий CSV с одной
ячейкой не содержит целого пространственного поля.

## Корректность представления и ограничения

- Адаптер поддерживает NCAR ERA5 LSP `ds633.0`, units=m, документированную
  previous-hour convention HRES. Метры переводятся в mm. Почасовые amounts не
  вычитаются друг из друга как forecast-start cumulative totals.
- Все кадры относятся к одному cycle и одной переменной. Отдельные ячейки
  отображаются отдельно; никаких точных равенств между разными SeriesKey не возникает.
- Цветовая шкала фиксирована для всех кадров. Переход между часами дискретный;
  временная интерполяция и произвольное деление суточных сумм не выполняются.
  Пропуски/отрицательные значения скрыты и посчитаны в metadata.
- Это карта native grid с прямоугольными lon/lat axes и приближённым соотношением
  масштабов по средней широте региона. Геодезическая точность проекции и
  пространственное восстановление осадков не заявляются.
- Выбирается hyperslab нужной области. Не более 12 кадров и по умолчанию
  1 000 000 значений; абсолютный разрешённый предел аргумента max_cells — 2 000 000.
  В CLI/UI большая область прореживается по пространству до этого бюджета;
  прямой API по умолчанию отклоняет её без `allow_downsample=True`. Native HDF chunk может
  охватывать глобальное поле одного цикла; cache ограничен 64 MiB. Архив целиком
  не загружается. Это не новый 200-GB benchmark.
- Карта — дополнительный интерфейс данных. Scientific bounds, H completeness,
  proof checker, старые Gate A/B и заявления о новизне не изменены.

Границы из [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/)
поставляются локально, данные public domain; геометрия служит ориентиром.
[Исходный GeoJSON](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_admin_0_countries.geojson)
сокращён до геометрий без таблицы свойств. В HTML включены и geometry, и Plotly JS;
тайлы, CDN и ключи картографических сервисов не требуются. Применяются обычные
[Plotly frames и controls](https://plotly.com/python/animations/), новая библиотека
не добавлена, uv.lock не менялся.

Проверки: tests/test_precipitation_map.py проверяет orientation/longitude wrap,
разделение циклов, сохранение уменьшающихся почасовых amounts, invalid cells,
лимит до чтения, output frames и Streamlit. Фактический HTML отрисован в локальном
headless Edge с переключением на шестой кадр; evidence:
[map-render.json](../reports/validation/map-render.json). Измеренный scientific
pilot не перезапускался и не выдаётся за проверку карты.
