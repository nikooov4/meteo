# Проверяемый профиль достаточной точности нового измерения

Дата: 2026-10-17. Реализованный исследовательский кандидат. Опирается на
известные difference constraints, parametric shortest paths и flow duality.
Приоритет специальной комбинации и её научная новизна НЕ установлены. Старые
Gate A и continuous-acquisition-v1 не заменяются этим исследованием.

## 1. Задача и поддерживаемая модель

В Case одна физическая серия, конечный объявленный набор интерпретаций H и
непрерывные множества допустимых неотрицательных накопленных рядов F_h.
Query — amount q(C)=C(t)-C(s) с допуском eps. Новый action — ОДНО измерение
количества m(C)=C(v)-C(u) в mm той же серии. Его ответ y удовлетворяет

    |y-m(C)| <= eta,   eta >= 0.

Модель допускает любое вещественное значение ошибки внутри этого интервала.
Распределение, независимость случайных ошибок, Gaussian noise и доверительная
вероятность не предполагаются. Correlated calibration, дискретный quantizer,
несколько новых измерений и threshold-профили требуют отдельных моделей.
Eta — заданная граница погрешности, не оценка точности реального прибора.

Два ряда C,D могут дать одинаковый ответ некоторого такого измерения тогда и
только тогда, когда |m(C)-m(D)|<=2*eta: интервалы возможных ответов пересекаются.
Обозначим rho=2*eta. Для каждой ordered пары h,k вычисляется

    V_hk(rho) = sup {q(C)-q(D): C in F_h, D in F_k,
                               |m(C)-m(D)| <= rho}.

Пустая пара не участвует в максимуме. Глобальный профиль
W_eta=max_hk V_hk(2*eta) равен максимальному диаметру Query после любого
допустимого ответа. Условие W_eta<=2*eps достаточно для midpoint/eps контракта
при любом ответе. Оно не доказывает полноту H и правильность метеоданных.

Важный результат интерфейса — диапазон допустимых eta. Его верхняя грань может
быть включена или исключена. Если H неполно, профиль относится только к
перечисленным интерпретациям; conditional_guarantee=false независимо от ширины.

## 2. Граф пары и начало области допустимости

Каждая интерпретация — difference network C(j)-C(i)<=w. Проверка глобальной
согласованности предшествует проекции: далёкий от Query конфликт не теряется.
Все endpoints действий заранее включаются в ограниченную рабочую модель.

В двух копиях можно совместить C(u)=D(u), поскольку начало отсчёта накопления
произвольно. Концы v НЕ склеиваются. Добавляются два ребра

    C(v) -> D(v), weight=rho
    D(v) -> C(v), weight=rho.

Они эквивалентны |m(C)-m(D)|<=rho. При eta=0 эта конструкция возвращает прежнее
равенство ответов. Склейка всех концов нескольких disconnected измерений
по-прежнему недопустима и не реализована.

Пусть B — согласованный базовый граф пары без двух новых рёбер, a=C(v), b=D(v),
d_B — его shortest-path bounds. Область допустимости пары имеет вид

    rho >= r_hk = max(0, -d_B(a,b), -d_B(b,a)),

где отсутствующий путь не даёт ограничения. Простой цикл с одним новым ребром
имеет вес rho+d_B(обратный путь); цикл, использующий оба противоположных новых
ребра, не даёт нового условия при rho>=0. Этим объясняется формула.

В сертификате формула не принимается на доверии. При r_hk>0 прилагается
symbolic cycle с весом b0+k*rho, k>0, равным нулю при r_hk и отрицательным ниже.
Полная feasible point при r_hk доказывает достижимость границы; при больших rho
эта же точка остаётся допустимой. Checker непосредственно проверяет оба факта.

## 3. Конечное описание всей непрерывной кривой

Цель q(C)-q(D) имеет суммарный положительный коэффициент не больше двух и
отрицательный не больше двух. Классическая dual задача — uncapacitated min-cost
flow из отрицательных терминалов в положительные. При согласованности нет
отрицательных циклов; достаточно рассмотреть не больше двух unit paths.

Простой путь использует не больше одного из двух новых противоположных рёбер:
использование обоих повторило бы вершину. Остальные участки лежат в B. Для
каждой пары source/target достаточно zero-noise пути и маршрутов через одно
из двух новых рёбер. Их стоимости — constant или constant+rho. Суммарная
стоимость двух путей имеет вид b_k+k*rho, k in {0,1,2}.

Отсюда для каждой допустимой ordered h-пары:

    V_hk(rho) = min_k (b_k + k*rho),   rho >= r_hk,

либо значение неограниченно для всей этой области. Не все три slopes обязаны
встречаться или быть активными; tightness ограничения «не больше трёх» не
заявляется. Это специализация стандартной сетевой duality, не новый общий
parametric-shortest-path algorithm и не новая worst-case complexity.

Каждый конечный профиль пары описывается не больше чем тремя аффинными
функциями и их активными интервалами. Глобальный максимум по H может иметь
больше частей и скачки при активации новых пар. Нельзя переносить concavity
одной пары на объединение метаданных или линейно интерполировать через скачок.

## 4. Как проверяется весь континуум ошибок

Каждая affine upper bound снабжается полными путями из исходных ограничений и
symbolic noise edges. Checker суммирует веса, считает коэффициенты rho и
проверяет баланс потоков против исходной Query-цели. Поэтому доказана верхняя
граница для каждого rho, без доверия к shortest-path search.

Для ограниченного интервала [r0,r1] приложены полные допустимые пары рядов в
обоих концах. Они достигают заявленной affine границы. Выпуклая комбинация
этих точек допустима при таком же сочетании r0,r1, поскольку все inequalities
линейны по потенциалам и rho. Query тоже линейна. Следовательно, достигающая
точка существует при КАЖДОМ промежуточном параметре, а не только на сетке.
Это математическое доказательство допустимости, не восстановление фактических
почасовых осадков интерполяцией.

На последнем интервале [r0,infinity) даны начальная достигающая точка и affine
направление d. Для исходных рёбер проверяется d(v)-d(u)<=0, для noise edges
проверяется d(v)-d(u)<=1, а производная Query равна slope профиля. Точка
z(rho)=z(r0)+(rho-r0)*d доказывает достижимость для сколь угодно больших конечных
rho. При неограниченной цели вместо этого предъявляются feasible point и
recession ray с положительной Query-целью и нулевыми RHS производных всех рёбер.

Checker проверяет покрытие всех интервалов и всех ordered h-пар, исключение
несогласованных миров, activation cycle, hashes входов/действий и итоговую
границу eta. Он не импортирует compiler, shortest-path search или SciPy.
Агрегация допустимой точности перепроверяется отдельным обходом pieces;
producer рассчитывает её через affine inequalities. Это два разных пути расчёта.

## 5. Почему верхняя грань может быть строгой

Ручной синтетический пример: четыре последовательных часа, два layout.

| Интерпретация | q: первый час | m: второй час | Остальные два часа |
|---|---:|---:|---|
| h0 | 0 | 0 | 10, 2 |
| h1 | 10 | 2 | 0, 0 |

Наблюдения одинаковы по значениям, layout переставляет интервалы. В каждом h
все четыре amounts известны. Для нового измерения m при eta<1 интервалы ответов
двух layouts не пересекаются. Любой ответ различает layouts и Query точна.
При eta=1 возможен общий ответ y=1: ошибки +1 и -1 допустимы. Query тогда
может быть 0 или 10. При eps=1 получаем безопасное множество eta in [0,1).

    radius_supremum = "1"
    safe_at_supremum = false

Сообщение «максимальная допустимая ошибка 1 mm» без второй строки было бы
ложной гарантией на самой границе. Это diagnostic counterexample, не заявление
о первом обнаружении подобного эффекта в математике.

Во втором примере daily total=12, Query=первые 12 часов, action=последние 12.
Получается W_eta=min(12,2*eta). При eps=1/2 безопасно eta<=1/2, включая границу.
Измерение первых шести часов оставляет W=12 уже при eta=0 и не подходит.

## 6. Реализации и сравнение

`full`: базовый граф двух полных миров; exact rational Bellman-Ford без
terminal projection и междействийного reuse. `compiled`: тот же полный граф,
но shortest paths предлагает SciPy Johnson. Перед использованием каждого пути
его вес пересчитывается Fraction, проверяются все reduced edge inequalities и
достижимость. Numerical proposal, не прошедший проверку, заменяется exact
Bellman-Ford; fallback считается. Таким образом compiled comparator сохраняет
тот же точный сертификат, а не получает иной tolerance contract.

`terminal`: shared per-world paths вычисляются один раз для batch; каждая пара
проецируется на Query и measurement endpoints. После склейки только u остаётся
не больше семи value-вершин. Полные primal witnesses и checker остаются работой
на всём ограниченном Case и включены в end-to-end замер. `terminal_no_reuse`
пересчитывает нужные per-world пути для каждого action: это ablation reuse,
при сохранении projection и остальных компонентов.

Independent paired LP строит две копии elementary increments напрямую из raw
observations и добавляет две inequalities на разность measured sums с RHS
2*eta. Не импортирует graph/compiler/checker. Результат численный; tolerance
сравнения 1e-7. LP на конечной сетке — дополнительная проверка реализации,
но не сертификат всей кривой и не equal-contract comparator её construction time.

Frozen protocol: configs/experiments/precision-frontier-v1.json. Новый output,
seeds/regimes, go/no-go, compiled comparator и ablation зафиксированы до timings.
Старые отрицательные/положительные pilots сохраняются. Новые результаты —
experiments/runs/precision-frontier-v1 и reports/precision_frontier.md.

## 7. Scope и ограничения

Сохраняются limits 128 endpoints, 16 H, 128 действий и 4096 ordered action-pairs.
Все профили относятся к одной будущей скалярной interval acquisition и amount
Query. Threshold Query, noisy metadata, several disconnected measurements,
continuous Bayesian VOI/DRD и adaptive optimal policy не реализованы этим
расширением. Старый exact threshold solver остаётся отдельной функциональностью.

Timeout и unsupported input не возвращают частичную гарантию. Incomplete H
всегда даёт incomplete_model. Теоретическая форма profile не доказывает полноту
H, calibration или физическую точность прибора. Гипотетическое новое измерение
не считается доступным только потому, что его интервал можно записать в JSON.

Источник математических overlap-рисков и проверенные страницы литературы:
literature_delta_2026_10_17.md. Независимый внешний review пока отсутствует.
