# Offline map outlines

Source: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_admin_0_countries.geojson

Terms: https://www.naturalearthdata.com/about/terms-of-use/ — Natural Earth data is
public domain. Retrieved 2026-10-18. The companion JSON keeps the 177 feature
geometries and source/license information; the property tables were omitted.
No coordinate interpolation or geometric simplification was introduced here.

These low-resolution outlines provide geographic context for a grid visualization.
They do not supply precipitation data or verify Query certificates.
