Сохранённые измерения — основание чисел в докладе. Статусы `running`,
`interrupted`, `not_run` и `pending` означают незавершённую проверку и не заменяются
словом «доказано». Научный подход, новизна, независимая экспертиза и нагрузочный
эксперимент отвечают на разные вопросы.

## Что можно сказать на защите

«MeteoBridge получает обоснованные границы ответа на запрос к накопленным
метеоданным. Он учитывает неоднозначные метаданные и нехватку временной
детализации, выдаёт проверяемое обоснование и оценивает, какое дополнительное
измерение с какой допустимой ошибкой поможет ответить на запрос.
Разработан специализированный метод вычисления и проверки полного профиля
требований к точности такого измерения. Корректность реализации и вычислительная
польза исследованы в сохранённых экспериментах; мировой приоритет не установлен».

## Быстрый запуск

Команды выполняются из корня репозитория, а не из `defense/`:

```powershell
uv sync --frozen
uv run streamlit run ui/app.py --server.address 127.0.0.1
# Во втором терминале, если сервер карты ещё не запущен:
uv run python scripts/serve_precipitation_map.py --manifest data/scale/weather-global-10gb-v2/manifest.json --scale-report reports/weather-10gb/scale/scale_report.json --port 8765
```

Карта: <http://127.0.0.1:8765/synthetic_global_animation.html?view=10gb>.
Если порт уже занят работающим viewer, повторный запуск не нужен.
Для первого воспроизведения больших данных нужен отдельно подготовленный archive;
в Git лежат код, небольшие примеры, manifests и результаты, а не сотни гигабайт.

Копии старых документов снабжены [manifest](sources/manifest.json): исходный путь,
SHA256 исходника и копии. В копиях исправлены только локальные ссылки для навигации.
Исторические даты, объёмы и ограничения не превращены в результаты новой версии.
