# Сценарий демонстрации на 10–12 минут

## До показа

Откройте этот файл, Streamlit, мировую карту и `05_experiments_ru.md`.
Запускайте команды из корня проекта. Сеть и GPU для подготовленных данных не нужны.

```powershell
uv run streamlit run ui/app.py --server.address 127.0.0.1
```

Если viewer ещё не работает:

```powershell
uv run python scripts/serve_precipitation_map.py --manifest data/scale/weather-global-10gb-v2/manifest.json --scale-report reports/weather-10gb/scale/scale_report.json --port 8765
```

Ссылка: <http://127.0.0.1:8765/synthetic_global_animation.html?view=10gb>.
При проблемах с сервером покажите сохранённый screenshot
`sources/reports/validation/archive-map-preview.png` и сохранённые результаты.
Не запускайте генерацию 200 GB во время защиты.

## 0:00–1:00 — постановка

«Из суточной суммы 12 mm нельзя узнать утреннюю сумму. Дополнительно может быть
неясен смысл временной метки. Система должна показать, что следует из данных,
и какое дополнительное наблюдение поможет получить нужный ответ».

## 1:00–4:00 — четыре исхода Query

В Streamlit → Offline demo последовательно выберите:

1. `overlap-exact`: показать единственный ответ из перекрывающихся интервалов.
2. `overlap-bounded`: показать lower/upper и два допустимых witness ряда.
3. `conflict`: показать невозможность совместить исходные ограничения.
4. `insufficient-data`: показать [0,12] для половины суток при известной суточной сумме.

В последнем случае объяснить: вопрос о метаданных не добавляет измерение.
Реальный аналог: «Локальный файл» → `defense/examples/native_resolution_case.json`.
Все 12 hourly observations сохранены; запрос за полчаса остаётся диапазоном.
Для иллюстрации выбран случай с максимальной шириной среди всех 72, не правило
отбора benchmark. Подробности и ограничения — в документе 08.
Отдельно показать `incomplete-h`: полнота H не подтверждается самим сертификатом.
Не смешивать конфликт данных, неполную модель и недостаток наблюдений.

## 4:00–6:00 — исследовательский метод

Показать подготовленный daily-complement пример:

```powershell
uv run meteo acquisition precision --case experiments/runs/precision-diagnostics-v1/daily/case.json --actions experiments/runs/precision-diagnostics-v1/daily/actions.json --radii 0,1/10,1/2,1 --output outputs/defense-precision
uv run meteo acquisition precision-verify --directory outputs/defense-precision
```

Для измерения второй половины суток профиль `W(eta)=min(12,2*eta)`.
При eps=0.5 допустимо eta<=0.5. Затем открыть jump-пример из той же папки:
существует случай, где безопасно eta<1, но eta=1 уже небезопасна.
Объяснить, зачем результат хранит включение границы и сертификат всего профиля.

Не утверждать, что LP сам по себе новый или что конечная сетка LP доказывает
весь континуум: полную кривую проверяет отдельный checker.

## 6:00–8:00 — мировой viewer

В левом верхнем углу задать:

- начало `2023-03-01 06:00` UTC;
- конец `2023-03-03 06:00` UTC;
- «Сценарий 0» → «Показать».

Нажать Play, затем Pause, приблизить регион колёсиком и перетащить карту.
Нажать «Весь мир». Показать смену «Сценарий 1» и сохранение выбранной области.
В раскрываемых данных показать manifest SHA256 и источник.

Назвать ограничения: это синтетика v2 из ERA5 LSP, не наблюдавшийся прогноз.
Эпизоды независимы каждые 12 часов; их идентификатор виден под датами.
Зум не добавляет разрешение сетке 1°. Архив 10.084 GB читается по кадрам,
259 200 bytes на hourly field, cache до четырёх кадров.

## 8:00–10:00 — фактические эксперименты

Открыть [05_experiments_ru.md](05_experiments_ru.md) и интерактивные figures.
Показать отдельно:

1. Исторический synthetic-200GB full streaming scan и ограниченный Query batch.
2. Новый partition-wide precision experiment: учитывать только фактический статус.
3. Новый реальный ERA5 эксперимент: исходные значения реальные, укрупнение и
   альтернативный metadata shift контролируемые; documented H1 — отдельная ветка.
4. Границы одного Query при возвращении исходных hourly observations.

Если большой job имеет статус running/interrupted, так и сказать. Не приписывать
ему результаты уже завершённого исторического scan или нового реального пилота.

## 10:00–12:00 — вклад и вопросы

«Предлагаемый вклад — конкретный способ вычисления и проверки полного профиля
требований к точности дополнительного наблюдения с конечными альтернативами
метаданных. Известные математические основы признаны; мировой приоритет пока
не установлен. Большой архив проверяет инженерную применимость, реальные значения
проверяют прикладную корректность, сравнение с литературой — содержательный delta».
