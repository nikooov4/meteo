# Данные работающей карты

`era5/` — реальные исходные NCAR ERA5 LSP NetCDF и контрольные файлы докачки.
Карта и вкладка загрузок используют эту папку по умолчанию.
Данные не добавляются в Git и не входят в сборку Visual Studio.

Прежняя папка `data/real/era5-weather-reference` перенесена в `data/era5`.
Имя, содержимое и SHA256 каждого из 13 исходных файлов сохранены.
Для внешнего архива: `./start_app.ps1 -Data 'D:\ERA5'`.

Исследовательские калибровочные данные, DWD и прежние fixtures удалены вместе
со старым проектом по запросу пользователя. Исходные NetCDF этой карты не удалялись.
